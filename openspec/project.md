# Annotate it — план развития

Плагин для DeepSeek Harness: разметка и ревью чатов и документов.
Репо: https://github.com/walorne/dsh-annotate-it

## Цель

Дать возможность выделять фрагменты в **чате** и в **документах** из правой панели,
ставить к ним заметки/комментарии/быстрые ответы и отправлять всё одним сообщением.

## Готово (v1.5.7)

- Выделение → панель: быстрые ответы + свой комментарий + цитата.
- Диктовка голосом (браузер — Web Speech API; десктоп — системная).
- Лента заметок над композером, отправка одним сообщением.
- Оранжевая подсветка + карточка истории при наведении + перепривязка.
- Два режима на чат: ожидание / рецензирование.
- Аннотация документов: markdown, код, PDF, Office.
- Редактируемый словарь быстрых действий.
- Тёмный UI «чёрный с каёмочкой», иконка, страница-деталь, GitHub.
